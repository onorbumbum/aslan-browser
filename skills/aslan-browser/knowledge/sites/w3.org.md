# w3.org

## W3C Technical Reports

- `r.jina.ai/https://www.w3.org/TR/...` can return HTTP 401 for W3C TR pages.
- Aslan Browser loads W3C TR pages normally. Use:
  ```bash
  aslan nav https://www.w3.org/TR/skos-primer/ --wait idle
  aslan text --chars 50000 > /path/to/source.txt
  ```
- `aslan text` extraction is clean enough for teach-me/course research on W3C specs and primers, including table of contents, abstract, examples, and section prose.
