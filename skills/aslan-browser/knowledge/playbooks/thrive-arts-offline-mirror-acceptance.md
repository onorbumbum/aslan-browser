# Thrive Arts offline mirror acceptance

## Inputs

- Absolute path to the packaged offline export directory

## Prerequisites

- Export generated by `scripts/static-export/build-offline.mjs`
- Open the artifact directly with `file:///.../index.html`

## Checks

1. Navigate with `aslan nav file:///ABSOLUTE/PATH/index.html --wait load`.
2. Confirm the FAQ class fragment is absent and hooks exist:
   - `document.body.innerText.includes("svg]:rotate-180") === false`
   - `[data-offline-accordion-trigger]`
   - `[data-offline-video-trigger]`
   - `[data-offline-program-filter]`
3. Click the first `[data-offline-accordion-trigger]`. Resolve its panel through `aria-controls`; confirm `aria-expanded="true"`, `panel.hidden === false`, and non-empty answer text.
4. Click `[data-offline-program-age="4-5"]`. Confirm the active control has `aria-pressed="true"` and the only visible cards are `mini-keys` and `art-fundamentals`.
5. Click the first `[data-offline-video-trigger]`. Confirm the modal is visible and the player has a local `file:` `currentSrc`, `paused === false`, `readyState === 4`, and no media error.
6. Close with `[data-offline-video-close]`.

## Notes

- `aslan nav file:///...` executes the classic inline interaction scripts and loads local media.
- An `<img>` with no `src` can report `complete && naturalWidth === 0`; exclude missing `src` values when checking genuinely broken images.
